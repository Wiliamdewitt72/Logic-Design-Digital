**Alarma de Temperatura de la Incubadora Neonatal**

Una incubadora neonatal requiere un sistema de alerta física. Suponga que el sensor de temperatura entrega una lectura digital de 4 bits (A). El médico establece una temperatura de referencia también de 4 bits (B). El sistema de alarma se diseñara en la tarjeta amiba 2, ingresando las dos temperaturas con los interruptores de desplazamiento.

Diseñar un circuito que reste la temperatura del sensor menos la de referencia (A - B) utilizando un sumador de 4 bits y compuertas XOR para implementar el complemento a dos de forma dinámica.

*Requisitos de Diseño:* 
Mostrar la diferencia de las dos temperaturas en los LEDs
Si A - B es positivo, el sistema enciende un LED indicador de "Temperatura Alta".
Si A - B es negativo, el sistema enciende un LED indicador de "Temperatura Baja".
Si A - B es cero, el sistema no enciende ningun indicador.
